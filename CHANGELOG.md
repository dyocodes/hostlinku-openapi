# Changelog

## 0.1.0 - 2026-11-18

- Initial release.
- OpenAPI 3.1.0 specification (`openapi.json`) covering `GET /v1/models`, `POST /v1/chat/completions`, `POST /v1/messages`, `POST /v1/messages/count_tokens`, `POST /v1/responses`, and `GET /api/public/models`.
- Postman Collection v2.1.0 (`postman/hostlinku-api.postman_collection.json`) pre-configured with `baseUrl` and `apiKey` variables across all 6 endpoints.
- Zero-dependency validator script (`scripts/validate-specs.mjs`) and CI workflow.
- Multilingual README (`en`, `id`, `ja`, `zh-CN`).
